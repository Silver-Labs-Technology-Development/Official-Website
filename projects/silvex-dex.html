SilvEx DEX

On-chain exchange research that keeps execution separate from discovery.

Current development statusDevelopment — experimental contractsSource-based overview · October 2026

SilvEx DEX is the on-chain exchange engineering track. Contract prototypes and integration boundaries are being developed; an external DEX pair in Silver Scan is not a usable or audited SilvEx swap. The DEX runtime and DEX Node remain separate architecture concerns.

View development source ↗Contribute or collaborate
01 / ENGINEERING

What has already been built

  • The repository contains AMM-related experimental contracts and local deployment scripts.
  • Testnet tooling and development architecture have been initiated.
  • No public routed swaps or audited liquidity product are verified.
02 / PRODUCT

What the product is intended to provide

  • Supported-chain quote and swap adapters with proper source asset identifiers.
  • Transparent pool reserves, fees and route disclosure once contracts are audited.
  • Wallet-driven signing and clear error/recovery states for supported networks.

These are separate current and future capabilities, not a claim that every function is already operational.

03 / GET STARTED

How to use or preview

Inspect the code and test locally with valueless testnet assets. Do not rely on preview contracts for real tokens.

04 / PARTICIPATE

How to get involved

Solidity/security reviewers, formal verification researchers, smart-contract developers and interface designers can help assess invariants.

Start from the repository's issues, documentation, test instructions or contribution process. Do not share private keys or production credentials.

05 / RELEASE READINESS

When will it be live?

No public swap release date announced. Security validation is a prerequisite.

Before a public readiness claim, these milestones require evidence:

  • Prove testnet swaps and consistent quote calculations.
  • Audit contract permissions, pool invariants, oracle assumptions and slippage protection.
  • Validate independent RPC/node indexing and wallet confirmations before any public launch.

Launch dates are not estimates unless published separately by the project. Repository activity and passing local tests do not establish safe public operation.

06 / ECOSYSTEM

Silver Labs integrations

SilvEx exchange UI, SilverPay wallet signing and Silver Scan informational DEX discovery.

Each integration needs separate compatibility, data-quality and security verification. A project being listed or featured does not mean wallets, pools or markets are live.
