Silver Scan

One research center for every coin you care about.

Current development statusActive development — market terminal and BTCS L1 explorerSource-based overview · October 2026

Silver Scan is Silver Labs' independent explorer and cryptocurrency intelligence platform—not a replacement for the Bitcoin Silver organization's explorer. It is being built to combine coin research, market data, mining information, token identities, DEX discovery and verified blockchain activity in one recognizable destination.

View development source ↗Contribute or collaborate
01 / ENGINEERING

What has already been built

  • A Python BTCS L1 explorer/indexer prototype supports blocks, transactions and address-history views.
  • A separate development branch provides Markets, Coin Watch, DEX Scan, coin profiles, historical price charts, dominance graphics and source-attributed Fear & Greed data.
  • The indexing layer has tests for integer-satoshi accounting, bounded synchronization and chain reorganization handling.
02 / PRODUCT

What the product is intended to provide

  • Market rankings, price/volume/supply charts, project profiles, provider provenance and watchlists.
  • Mining network data and independently sourced pool discovery, with chain-verified explorer data when adapters exist.
  • Future cross-chain transaction/token/NFT coverage, campaign analytics and project intelligence.

These are separate current and future capabilities, not a claim that every function is already operational.

03 / GET STARTED

How to use or preview

The current development build runs with a local Python API. Browsing a static frontend alone does not provide live market data or BTCS RPC access. Preview instructions and requirements live in the Silver Scan repository.

04 / PARTICIPATE

How to get involved

Data-visualization designers, blockchain indexer engineers, API integrators, security testers and accessibility contributors are especially welcome.

Start from the repository's issues, documentation, test instructions or contribution process. Do not share private keys or production credentials.

05 / RELEASE READINESS

When will it be live?

No public launch date announced. Market and explorer preview milestones are ahead of full multi-chain support.

Before a public readiness claim, these milestones require evidence:

  • Connect and monitor a production-grade API for market data with provider licensing and rate-limit controls.
  • Complete audited mainnet indexing, reorganization recovery and verification against independent nodes.
  • Expand network-specific adapters and source-backed analytics before claiming broad multi-chain coverage.

Launch dates are not estimates unless published separately by the project. Repository activity and passing local tests do not establish safe public operation.

06 / ECOSYSTEM

Silver Labs integrations

Silver Pool statistics, future SilvEx market reference APIs, SilverPay token discovery and listing campaign analytics.

Each integration needs separate compatibility, data-quality and security verification. A project being listed or featured does not mean wallets, pools or markets are live.
