Mining infrastructure

Silver Pool

One mining destination. Many proof-of-work networks.

Current development statusDevelopment — BTCS locally testedSource-based overview · October 2026

Silver Pool is Silver Labs' mining infrastructure project. Its code already includes a working BTCS-focused Stratum backend, read-only pool API, share accounting and website work. The direction is a broader, multi-algorithm pool where miners select verified coins rather than treating every chain as Bitcoin Silver.

01 / ENGINEERING

What has already been built

  • BTCS SHA-256d Stratum V1 workflow and local mainnet node connection have been exercised in development.
  • Share validation and PPLNS reward-accounting components exist, with a frontend/dashboard codebase.
  • Public API health and status endpoints and hosting/deployment work have been implemented.
02 / PRODUCT

What the product is intended to provide

  • Per-coin status and algorithm-specific connection guides, wallet/worker dashboards and transparent published fee schedules.
  • Independent full-node adapters, chain-specific job validation, block confirmation and maturity handling.
  • Future integrations with Silver Scan mining analytics and supported PoW-S accounting.

These are separate current and future capabilities, not a claim that every function is already operational.

03 / GET STARTED

How to use or preview

Read the repo's launch checklist and local development instructions. Public Stratum connectivity and real paying-pool operation are not yet verified. Do not move miners based on a preview endpoint.

04 / PARTICIPATE

How to get involved

Node operators, mining protocol engineers, pool security reviewers, backend engineers and frontend contributors can help test coin adapters, deployment boundaries and external ASIC connections.

Start from the repository's issues, documentation, test instructions or contribution process. Do not share private keys or production credentials.

05 / RELEASE READINESS

When will it be live?

No committed public launch date. The next milestone is a verifiable BTCS public pilot; multi-coin support will follow one network at a time.

Before a public readiness claim, these milestones require evidence:

  • Verify public DNS/TLS, an external miner acceptance test and operational node resilience.
  • Implement and independently verify payout signing, maturity, reconciliation, recovery and off-host backups.
  • Add non-BTCS networks only after isolated node, protocol and share tests pass.

Launch dates are not estimates unless published separately by the project. Repository activity and passing local tests do not establish safe public operation.

06 / ECOSYSTEM

Silver Labs integrations

Silver Scan mining dashboards, future PoW-S multi-asset accounting, future SilvEx eligibility reviews.

Each integration needs separate compatibility, data-quality and security verification. A project being listed or featured does not mean wallets, pools or markets are live.
