Status reflects inspected local repositories and tests. It does not imply production readiness, security certification, or support commitments.

01 / WALLET

SilverPay

SilverPay is one product: the wallet is its initial account and asset-management functionality. The existing service and web Studio provide partial read-only L1/L2 views; no separate mobile codebase was found.

Next: advance the wallet foundation and establish a secure account/signing architecture. Payment processing is a later SilverPay milestone.

PROTOTYPE · READ-ONLY FOUNDATION

02 / ASSETS

SilverForge & BSNA

The local BTCS L2 Studio and asset service exercise ERC-20 and proposed BSNA-FTS1 flows. A separate static preview constructs wallet-authorized transactions for Ethereum, BNB Chain, and Solana; BTCS L2 remains disabled there.

Next: verify transaction layouts with compatible wallets on test networks and complete protocol review. The local frontend is not deployed and no public source repository exists.

DEVELOPMENT · LOCAL PREVIEWS

03 / EXECUTION

BTCS L2

The local prototype includes an EVM harness, JSON-RPC, and opt-in single-operator sequencing. A local engineering report records focused test coverage; the sequencer remains trusted and development-only.

Next: verify the full L1-to-L2-to-withdrawal lifecycle and improve restart, recovery, and reorganization behavior.

PROTOTYPE · LOCAL CHECKOUT

04 / CENTRALIZED EXCHANGE

SilvEx CEX

No exchange account, custody, matching, deposit, or withdrawal implementation was found. OpenCEX is only an upstream candidate under assessment; no real-value trading is available.

Next: finish upstream license, security, and architecture review before deciding whether to adopt or build.

PLANNED · NO TRADING

05 / DECENTRALIZED EXCHANGE

SilvEx DEX

No supported pool, quote route, or reviewed swap contract has been verified. There is no executable swap or market destination.

Next: select a supported chain and reviewed protocol, then demonstrate a reproducible testnet swap before exposing trading interfaces.

PLANNED · NO SWAPS

06 / EXCHANGE INFRASTRUCTURE

SilvEx DEX Node

No independently deployable indexer, router, quote service, or DEX node was found. Centralized exchange services and on-chain DEX infrastructure are separate systems.

Next: define the minimum services for a verified DEX design, including stale-data and reorganization handling.

PLANNED · NO NODE SERVICE

07 / EXPLORER

Silver Scan

No independent indexer or explorer implementation was found. Node RPCs and Studio views are not a substitute for a maintained explorer.

Next: define indexed data, bounded read APIs, pagination, and reorganization behavior.

PLANNED · NO CODEBASE

08 / MINING

BTCS mining pool

BTCS Core exposes node mining interfaces. No separate pool service, Stratum share validation, payout accounting, or pool operations were found; compatibility with ckpool is under investigation.

Next: verify BTCS proof-of-work and block-template requirements before selecting or adapting a pool implementation. Pool mining is distinct from L2 sequencing.

PLANNED · NO POOL SERVICE

09 / COMPUTE

POW-S

No POW-S implementation or supported API was found in the inspected workspace.

Next: clarify product scope and operating assumptions before implementation.

RESEARCH · NO CODEBASE FOUND

VERIFIED LOCALLY

Local product foundations

BTCS L2 execution and SilverPay read-only integration have local tests; SilverForge has a separate static frontend prototype with transaction-construction tests.

ACTIVE ENGINEERING

Settlement and recovery research

BTCS L2 lifecycle and recovery verification continues. Sequencing remains trusted, and the full L1-to-L2-to-withdrawal lifecycle is not yet established.

PLANNED

Independent product services

Private development repositories and shared contracts are still needed for SilverPay and SilverForge; an explorer and pool service have not been implemented.

UNRESOLVED RESEARCH

SilvEx, pool, and POW-S

CEX, DEX, DEX Node, pool, and POW-S each need verified designs and dedicated engineering. No operational capability is claimed.
