PROJECT NOTES

What exists.
What comes next.

Status reflects inspected local repositories and tests. It does not imply production readiness, security certification, or support commitments.

01 / WALLET

SilverPay

The existing service reads BTCS Core wallet data and BTCS L2 account state. The Studio has a partial wallet view with separate L1 and L2 balances.

Next: approve product ownership and a secure account/signing architecture before adding wallet actions.

PROTOTYPE · READ-ONLY

02 / ASSETS

SilverForge & BSNA

Token Studio and the asset service exercise ERC-20 and BSNA-FTS1 deployment, fee estimation, logo handling, and authorized minting on an ephemeral local chain.

Next: separate protocol specification and key management from this development-only service.

PARTIAL · LOCAL ONLY

03 / EXECUTION

BTCS L2

The existing local prototype includes an EVM harness, JSON-RPC, and opt-in single-operator sequencing. The model is trusted, and the pool is in-memory.

Next: continue independent execution, restart/recovery, reorg, and settlement verification work.

LOCAL CHECKOUT · NO PUBLIC REPOSITORY LINK

04 / EXCHANGE

SilvEx

No SilvEx DEX, CEX, or DEX Node checkout was found in the inspected workspace. There is no verified trading, swap, or custody implementation to link.

Next: establish ownership, requirements, and security boundaries before selecting an architecture.

PLANNED · NO CODEBASE FOUND

05 / EXPLORER

Silver Scan

No independent indexer or explorer implementation was found. Existing Studio block views are not a substitute for a maintained explorer.

Next: define indexed data, reorg behavior, and supported read APIs.

PLANNED · NO CODEBASE FOUND

06 / MINING

BTCS mining pool

BTCS Core has node-level mining RPC interfaces. No separate pool service, share accounting, payout system, or monitoring integration was found.

Next: identify pool ownership and define safe node-observation interfaces; keep pool mining distinct from L2 sequencing.

PLANNED · NODE APIs EXIST

07 / COMPUTE

POW-S

No POW-S repository or supported API was found in the inspected workspace.

Next: clarify product scope and operating assumptions before implementation.
