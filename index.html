01 / WALLET

SilverPay

SilverPay is one product encompassing its wallet and payment services; the wallet is not a separate product. The public SilverPay repository contains the wallet application. The wallet supports watch-only accounts, ERC-20 tracking, and wallet-signed sends against a disposable local BTCS L2 node; payment processing remains a later phase, and no separate mobile codebase was found.

Next: advance the unified SilverPay foundation and establish a secure account/signing architecture before expanding wallet and payment capabilities.

PROTOTYPE · LOCAL DEVELOPMENT WALLET

02 / ASSETS

SilverForge & BSNA

The local BTCS L2 Studio and asset service exercise ERC-20 and proposed BSNA-FTS1 flows. A separate static preview constructs wallet-authorized transactions for Ethereum, BNB Chain, and Solana, with an experimental BTCS L2 profile restricted to an identity-checked local development node.

Next: test the BTCS L2 profile against an isolated running node, verify external-chain transaction layouts with compatible wallets on test networks, and complete protocol review. No public BTCS L2 deployment is supported; the standalone frontend remains a local preview.

DEVELOPMENT · LOCAL PREVIEWS

03 / EXECUTION

BTCS L2

The local prototype includes an EVM harness, JSON-RPC, and opt-in single-operator sequencing. A local engineering report records focused test coverage; the sequencer remains trusted and development-only.

Next: verify the full L1-to-L2-to-withdrawal lifecycle and improve restart, recovery, and reorganization behavior.

PROTOTYPE · LOCAL CHECKOUT

04 / EXCHANGE

SilvEx

SilvEx has a development trading terminal with charting and read-only external market data. Reference provider volume is not native SilvEx executed volume. Production custody, matching, deposits and withdrawals are not verified.

Next: secure administration, implement and validate the matching, ledger and wallet boundaries before real-value trading.

DEVELOPMENT · NO LIVE TRADING

05 / DEX

SilvEx DEX

On-chain contract prototypes are separate from the Silver Scan DEX research interface. Searching external pairs is not an executable SilvEx swap or a claim of token verification.

Next: verify a testnet swap, quote service and contract security before showing supported routes.

DEVELOPMENT · NO PUBLIC SWAPS

06 / EXCHANGE INFRASTRUCTURE

SilvEx DEX Node

A planned repository records the service boundary only. No independently deployable indexer, router, quote service, or DEX node exists. Centralized exchange services and on-chain DEX infrastructure are separate systems.

Next: define the minimum services for a verified DEX design, including stale-data and reorganization handling.

PLANNED · NO NODE SERVICE

07 / RESEARCH & EXPLORER

Silver Scan

Silver Scan already contains a BTCS L1 Python explorer, RPC block/transaction lookup, address views and SQLite indexing. It is expanding into a multi-coin research terminal with Markets, Coin Watch, provider-backed data and DEX Scan. The current public frontend does not imply a production indexer or live provider backend.

Next: complete real provider UI and source timestamps, harden chain reorgs and indexing, then add verified Silver Pool and BTCS L2 connections.

DEVELOPMENT · NOT A FULL MULTICHAIN INDEXER

08 / MINING

Silver Pool

Silver Pool has a locally verified BTCS Stratum V1 server, node template integration, share validation, PPLNS accounting and a ten-page website. Cloudflare frontend work is separate from the pool API. Public Stratum access, third-party miner shares and secure payouts remain unverified.

Next: connect public API hosting, verify a real miner, complete backups/monitoring and audit payout infrastructure before operating a paying pool.

DEVELOPMENT · PAYOUTS DISABLED

09 / COMPUTE

POW-S

A planned research repository exists, but no POW-S implementation, customer model, or supported API has been defined.

Next: clarify product scope and operating assumptions before implementation.

SILVER SCAN RESEARCH TERMINAL

More than a block explorer.
Markets, watchlists and DEX discovery.

The Silver Scan direction includes searchable coin markets, Coin Watch, verified BTCS L1 exploration, pool statistics and DEX Scan. Every price, market metric and external trade volume must show its provider and freshness, with chain and contract IDs where relevant.

The existing explorer is a development prototype; not all research features or public APIs are deployed. Discovery is informational only and does not imply exchange listing or supported swaps.

DEVELOPER QUICKSTART

Clone, install, test.

These commands are taken from the current repositories. BTCS L2 requires Node.js 24.17.0. The wallet and SilverForge require Node.js 20.18.0 or newer. Use a disposable local node and test accounts; no command here publishes to a production network.

BTCS L2

EVM harness, settlement, deposits, withdrawals, and local RPC.

git clone https://github.com/Silver-Labs-Technology-Development/btcs-l2.git
cd btcs-l2/execution/evm
npm ci
npm test

SilverForge Studio

Token creation frontend with EVM, Solana, and local BTCS L2 profiles.

git clone https://github.com/Silver-Labs-Technology-Development/SilverForge-Studio.git
cd SilverForge-Studio
npm ci
npm test
npm run build

SilverPay wallet

Browser wallet for the local BTCS L2 development profile. Start a disposable node first; the Vite server proxies /rpc because the node sends no CORS headers. Injected-wallet sending is not yet verified while the node rejects the pending block tag.

git clone https://github.com/Silver-Labs-Technology-Development/SilverPay.git
cd SilverPay
npm ci
BTCS_L2_RPC_URL=http://127.0.0.1:8545 npm test
npm run build

Shared platform

Read-only L2 client, network identity schema, and repository tooling.

git clone https://github.com/Silver-Labs-Technology-Development/silver-labs-platform.git
cd silver-labs-platform/packages/btcs-l2-client
npm ci
npm test
npm run check:types

BTCS Core

Bitcoin Silver L1 node, RPC, and desktop wallet source.

git clone https://github.com/Silver-Labs-Technology-Development/Silver-Labs-Bitcoin-Silver-Development.git
cd Silver-Labs-Bitcoin-Silver-Development
cmake -B build
cmake --build build -j"$(nproc)"

Before contributing

Read the repository README and security policy. Keep changes small. Run the documented tests. Do not commit private keys, seed phrases, .env files, wallet data, or local chain databases. Open an issue before starting bridge, custody, or settlement changes.
