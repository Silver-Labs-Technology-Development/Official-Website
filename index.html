SILVER SCAN RESEARCH TERMINAL

More than a block explorer.
Markets, watchlists and DEX discovery.

The Silver Scan direction includes searchable coin markets, Coin Watch, verified BTCS L1 exploration, pool statistics and DEX Scan. Every price, market metric and external trade volume must show its provider and freshness, with chain and contract IDs where relevant.

The existing explorer is a development prototype; not all research features or public APIs are deployed. Discovery is informational only and does not imply exchange listing or supported swaps.

DEVELOPER QUICKSTART

Clone, install, test.

These commands are taken from the current repositories. BTCS L2 requires Node.js 24.17.0. The wallet and SilverForge require Node.js 20.18.0 or newer. Use a disposable local node and test accounts; no command here publishes to a production network.

BTCS L2

EVM harness, settlement, deposits, withdrawals, and local RPC.

git clone https://github.com/Silver-Labs-Technology-Development/btcs-l2.git
cd btcs-l2/execution/evm
npm ci
npm test

SilverForge Studio

Token creation frontend with EVM, Solana, and local BTCS L2 profiles.

git clone https://github.com/Silver-Labs-Technology-Development/SilverForge-Studio.git
cd SilverForge-Studio
npm ci
npm test
npm run build

SilverPay wallet

Browser wallet for the local BTCS L2 development profile. Start a disposable node first; the Vite server proxies /rpc because the node sends no CORS headers. Injected-wallet sending is not yet verified while the node rejects the pending block tag.

git clone https://github.com/Silver-Labs-Technology-Development/SilverPay.git
cd SilverPay
npm ci
BTCS_L2_RPC_URL=http://127.0.0.1:8545 npm test
npm run build

Shared platform

Read-only L2 client, network identity schema, and repository tooling.

git clone https://github.com/Silver-Labs-Technology-Development/silver-labs-platform.git
cd silver-labs-platform/packages/btcs-l2-client
npm ci
npm test
npm run check:types

BTCS Core

Bitcoin Silver L1 node, RPC, and desktop wallet source.

git clone https://github.com/Silver-Labs-Technology-Development/Silver-Labs-Bitcoin-Silver-Development.git
cd Silver-Labs-Bitcoin-Silver-Development
cmake -B build
cmake --build build -j"$(nproc)"

Before contributing

Read the repository README and security policy. Keep changes small. Run the documented tests. Do not commit private keys, seed phrases, .env files, wallet data, or local chain databases. Open an issue before starting bridge, custody, or settlement changes.
